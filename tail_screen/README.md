# 尾盘规则筛选

最新行情 → ST/停牌过滤 → 十项条件 → 规则与板块打分 → Markdown/HTML 报告。公开入口使用纯规则排序，不调用本地预测模块或交易接口。

在仓库根目录运行：

```bash
python tail_screen/wei_pan_cli.py --profile standard --mode B --show-config
python tail_screen/wei_pan_cli.py --profile strict --mode B --codes 600000,000001
python tail_screen/wei_pan_cli.py --profile relaxed --mode C --format md
```

第一条只打印配置，不请求网络。后两条使用最新公开行情；全市场逐只补日线会较慢，首次建议用少量 `--codes` 检查数据源。

## 三个参考版本

这些值是便于比较的起始配置，未经收益优化或独立样本验证。“强限制”只表示入围门槛较窄，不表示风险更低或预期收益更高。编辑 `wei_pan_core/config.py` 的 `SCREEN_PROFILES` 可保存自己的版本。

| 基准参数 | 强限制：`strict` | 标准：`standard` | 弱限制：`relaxed` | 单位与含义 |
|---|---:|---:|---:|---|
| `pct_chg` | 2.5%—6% | 2%—7% | 1%—8.5% | 当日涨幅；代码用小数，如 `.025` |
| `market_cap` | 40—150 | 30—200 | 20—300 | 总市值，亿元 |
| `vol_ratio` | 1.3—4 | 1.1—5 | 1—6 | 量比 |
| `turnover_rate` | 6%—12% | 5%—15% | 3%—20% | 换手率；代码用小数 |
| `limit_up_days` | 20 | 30 | 45 | 近 N 个交易日内有至少一次近似强涨幅日 |
| `ma20_deviation_band` | ±3% | ±5% | ±8% | `(现价-MA20)/MA20` |
| `amplitude_min` | 3% | 3% | 2% | `(最高-最低)/昨收` 的下限 |

近似强涨幅日采用日收盘收益 `>=9.8%`，没有按各板块、历史日期逐日计算法定涨停价；因此不是精确涨停识别。需要研究真实涨停时，应替换数据标记逻辑。

## 参数档位与时间模式分别选择

`--profile` 改上表的基准；`--mode` 改原有时间窗口、乘数和均线/板块分支，两者可以组合，例如 `--profile strict --mode B`。

| 时间模式 | K 乘数 | 使用的分钟窗口 | 附加形态 |
|---|---:|---|---|
| A | 1.20 | 14:00—14:29 | MA5>MA10>MA20>MA45；排除已标记新股及 688/300 前缀 |
| B | 1.00 | 14:00—14:44 | MA5>MA10>MA20 |
| C | 0.85 | 14:30—14:51 | MA5>MA20 或 MA5>MA10 |

默认 `--mode auto` 按上海时间 `<14:45` / `14:45—14:51` / `>=14:52` 选择 A/B/C。分钟窗口未形成、获取失败或样本不足时不通过，C 也不因缺失数据放行。固定分钟窗口并不表示能在更早时刻提前得到筛选结果。

对正区间使用 `下限×K×市场因子，上限÷K÷市场因子`；MA20 的零中心区间两端都除以该因子；涨幅日窗口为 `ceil(N/K)+市场放宽天数`。有效窗口必须在 1—60 个交易日内。环境闸门会进一步调整阈值或停止筛选，因此上表不是每次运行的最终门槛；用 `--show-config` 查看中性市场下的结果，报告中 `filter_report.thresholds` 记录实际阈值。A/B/C 的分钟窗口不同，不把三种模式的最终结果宣称为严格嵌套集合。

## 哪些选项可以改

- `--codes`：限定六位股票代码，逗号分隔；省略时尝试全市场。
- `--format md/html/both`：输出形式。
- `--capital`：仅改变报告中的模拟仓位金额，默认 100000 元；不改变筛选条件，不执行委托。
- `config.py` 的 `new_stock_days`：默认约 30 个交易日。上市天数由自然日近似换算，缺上市日期时按未知老股处理；需要准确新股过滤时必须补齐上市日期。
- `SCORE_BASE_WEIGHTS` / `SCORE_SECTOR_WEIGHTS`：评分权重，分别保持总和 70 / 30；这是排序参数，不是硬筛选条件。
- `GLOBAL_GATE` / `REGIME_RULES`：实验性的市场环境规则。默认先保持不变，再单独比较修改效果。
- `SELL_STRATEGIES`：报告中的模拟次日退出条件；不保证成交、不执行订单。模式 A 的报价区间仍是固定示意，不是可预测的次日开盘价。

## 日期与数据边界

`--date YYYY-MM-DD` 只接受上海时区今天，默认今天；不能改成过去某天来回测。行情 API 仍返回最新快照，休市或接口延迟时可能对应上一交易日，程序尚未在所有来源中可靠核验报价日期。日内更新还可能读到当天较早缓存，比较档位时应保持同一快照，并留意 `缓存/weipan_data_cache`。

板块多日收益现在请求截止日前 40 个自然日的窗口，3 日收益至少需要 4 个收盘价，5 日收益至少需要 6 个；不足、限流或匹配不到所属板块时，相应分项仍会退回中性分。代码列表来源全部失败时不再用固定示例股票冒充全市场，而是继续其他真实来源，最终取不到时报告失败。

为控制请求量，第一轮通过后只对当前顺序前 50 只请求分时；未检查到分时的股票不会通过第二轮。所属板块信息最多请求前 30 只，板块历史最多请求板块列表前 30 项。因此输出是受请求上限约束的候选排序，不能解释为完整全市场最高分排名。比较阈值时，应保持相同候选范围与行情快照。

本次公开整理验证了离线规则、真实取数函数与过滤/评分的字段衔接及 CLI，不表示所有联网来源持续可用。外盘、板块或上市日期缺失时仍可能使用中性值/近似值；报告必须结合缺失提示阅读。原项目的历史重建与回测函数保留为实验源码，公开入口不调用，不能据此宣称无前视的历史收益。
