# 核心模块说明

公开版的实际生效参数、三档基准和运行示例见 [模块使用说明](../README.md)。

- `config.py`：三档基准参数、评分权重、市场环境闸门、缓存路径。
- `hard_filter.py`：十项筛选、模式乘数与分时窗口。
- `data_fetcher.py`：最新行情与历史日线补充。
- `orchestrator.py`：规则流程；公开 CLI 固定禁用跨模块 ML 重排。
- `scorer.py`、`sector_ranking.py`：打分与板块信息；缺失项可能退回中性分。
- `report_formatter.py`：Markdown / HTML 报告。
- `stock_pool.py`：ST、停牌过滤与近似新股标记。

`backtest_data_reconstructor.py` 和 `run_wei_pan_backtest` 属于原项目实验代码，未验证历史时点估值、成分股与分钟数据完整性；公开 CLI 不调用它们。
