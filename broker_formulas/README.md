# 券商公式补充：通达信日线技术初筛

本目录提供三份可复制的通达信条件选股公式，方便在支持通达信公式语言的客户端中做日线技术初筛。它们只覆盖可用日线 OHLCV 表达的条件，**不是四项 Python 工具的完整移植**，不自动委托，也不计算收益。使用其它公式语言的券商客户端不能直接套用。

| 文件 | 覆盖内容 | 没有包含 |
| --- | --- | --- |
| [ema_pullback.tdx](ema_pullback.tdx) | EMA20 缩量回踩主信号 | MACD 辅助确认、乖离减仓、震荡提示、`--style` 退出规则 |
| [gap_open.tdx](gap_open.tdx) | 开盘严格突破上一根日线最高价 | 市值、PB、名称/ST/退市排除、历史股票池 |
| [tail_daily_prefilter.tdx](tail_daily_prefilter.tdx) | 涨幅、均线偏差、振幅、均线多头、近期强涨幅日 | 市值、换手率、实时量比、分钟形态、新股/板块过滤、环境闸门和评分排序 |

机器学习模型需要训练数据、特征处理和模型状态，不在这里硬译为公式。公式没有使用 `FINANCE`、`DYNAINFO` 的编号，也没有用 `VOL/MA(VOL,5)` 代替客户端的实时量比。

## 复制到客户端

1. 在支持通达信公式语言的客户端中找到公式管理器，选择“条件选股公式”并新建。不同券商版本的入口名称可能不同，可在帮助中查找“公式编辑器”。
2. 以纯文本打开其中一份 `.tdx`，复制全部内容到编辑器。这里的 `.tdx` 只是方便保存源码的文件扩展名，**不是可通过导入功能加载的加密公式包**。
3. 找到并修改 `PROFILE:=2;` 这一行：`1` 为强限制、`2` 为标准、`3` 为弱限制。除这个值外，不必同时修改其它行。中间变量使用 `:=` 赋值，最后只保留一条 `XG:` 输出。
4. 在客户端执行公式语法检查，再在条件选股界面选择**日线**与所需日期、股票范围和复权方式，下载足够的历史行情后运行。EMA 至少25根、跳空至少2根、尾盘初筛至少60根有效日线；建议载入更长历史。
5. 先选一只股票，对照同日起点和同一价格口径的 Python 参考值，再扩大范围。客户端显示“通过语法检查”也不等于策略有收益。

这些源码按官方函数说明编写，已做离线语义检查，**尚未在券商/通达信客户端中编译或运行验证**。不能据此声称某个券商版本可直接导入，客户端的保留变量名、函数实现或历史加载范围差异仍需现场检查。

## 三档条件与可修改值

### EMA 缩量回踩主信号

| 条件 | 强限制1 | 标准2 | 弱限制3 |
| --- | --- | --- | --- |
| `TOUCH`，回踩容差 | 0.01（1%） | 0.02（2%） | 0.03（3%） |
| `SHRINK`，当日量/5日均量上限 | 0.65 | 0.80 | 0.95 |

共同条件：收盘价在 EMA20 上方，最低价不高于 `EMA20×(1+TOUCH)`，当日量大于零且小于 `MA(VOL,5)×SHRINK`；趋势为当前 EMA20 高于9根之前的 EMA20，或最近10根里至少6根收盘在对应 EMA20 上方。5日均量**包含当天**；回踩条件只是最低价的上限，并没有限制当天最低价必须高于 EMA 的某条下界。

它对应 Python EMA 模块的缩量回踩主信号，不含该模块报告里的其它信号。EMA 周期在公式中固定为20，均量周期为5，趋势窗口为10；如果手动修改，需要同步修改参考计算及原模块参数，不能只改公式后继续声称三者一致。

### 跳空开盘突破昨高

| 条件 | 强限制1 | 标准2 | 弱限制3 |
| --- | --- | --- | --- |
| `GAP`，开盘超过昨高的最低幅度（%） | 0.5 | 0 | 0 |

共同条件：`O > REF(H,1)×(1+GAP/100)`，当日量大于零。`0.5` 表示0.5%，不是50%；等于阈值不入选。“昨高”是上一根有效日线最高价，不能简单取上一个自然日。标准、弱限制在这个技术子集上相同，二者在 Python 完整筛选中的市值/PB限制不同；公式没有凭空补上这些估值字段。

### 尾盘日线技术初筛

| 条件 | 强限制1 | 标准2 | 弱限制3 |
| --- | --- | --- | --- |
| `RETLO`—`RETHI`，当日涨幅区间 | 0.025—0.06 | 0.02—0.07 | 0.01—0.085 |
| `DEVLIM`，相对MA20偏差绝对值上限 | 0.03 | 0.05 | 0.08 |
| `AMPMIN`，日内振幅下限 | 0.03 | 0.03 | 0.02 |
| 近期强涨幅日窗口 | 20根 | 30根 | 45根 |

所有比例在本表中用小数，`0.025` 即2.5%。涨幅为 `(C-REF(C,1))/REF(C,1)`；均线偏差为 `(C-MA(C,20))/MA(C,20)`；振幅为 `(H-L)/REF(C,1)`。区间上下限均包含端点。共同要求 `MA5>MA10>MA20`、当日量大于零，且相应窗口内至少一次收盘涨幅不低于9.8%。后者只是**近似强涨幅日**，不识别不同板块及历史时期的实际法定涨停价。

它取 Python 尾盘模块**固定B模式、K=1、市场因子=1**时可表达的技术条件，不包含A/C时间窗口、分钟走势或市场环境调整。若股票通过公式，仍可能因 Python 的市值、换手率或分时等条件被剔除。Python 的分钟行情和当前快照必须另外获取，日线公式不能重建14:45的历史筛选状态。

三档均为工程起始值，未按收益优化。固定相同日线数据时，已实现的技术子集满足强限制通过集合包含于标准、标准包含于弱限制；完整 Python 工具和不同数据源之间不据此保证相同名单，更不能当作统一风险等级。

## 本地参考计算

`reference.py` 用 pandas 计算以上三类技术条件，方便检查日线和参数，不解析通达信源码，也不连接券商客户端。CSV只放一只股票，至少包含 `date,open,high,low,close,volume`。可用中文列名；股票标识列可为 `code`、`symbol`、`代码`、`股票代码` 中的一个。若没有标识列，程序无法发现被错误拼在一起的不同股票，请自行核对。日期应为无时区的本地交易日，代码列不能在同一CSV中变化。

从仓库根目录运行：

```bash
python broker_formulas/reference.py --kind ema --csv broker_formulas/example_daily.csv --profile standard --as-of 2026-09-30
python broker_formulas/reference.py --kind gap --csv broker_formulas/example_daily.csv --profile strict --as-of 2026-09-30
python broker_formulas/reference.py --kind tail --csv broker_formulas/example_daily.csv --profile relaxed --as-of 2026-09-30 --out outputs/formula_reference.csv
python -m unittest discover -s tests -p test_broker_formulas.py -v
```

[example_daily.csv](example_daily.csv) 是80根**合成日线**，股票代码只是示例标识，不是真实历史行情、选股记录或推荐标的。参考程序不联网，也不自动改变复权方式；CSV单位必须保持一致。这里的量条件均为同口径比例，`volume`全为股或全为手会得到同样比例，不能把不同来源的股与手混在一列。

`--as-of` 包含该日并在计算前剔除更晚的数据，休市日使用此前最后一根日线；输出同时记录请求日和实际末日。日线不足时输出 `status: insufficient_history`，而不是把它解释成正常的“未入选”。`--out` 保存每根日线的中间量、`history_ready`与`selected`，不指定则只打印末根摘要。

## 价格口径、初始化与验证边界

- 跳空公式和 Python 跳空模块比较时使用**未复权**日线；EMA通常选择同一来源的前复权日线。尾盘初筛要和 Python 比较时，也必须统一日线价格、昨收口径和截止时点。参考程序无法从一个普通CSV可靠判定其复权方式。
- 除权除息会机械改变未复权价差；当前版本前复权历史又可能随后来的公司行动调整。“没有写未来引用函数”不等于已具备无前视偏差的完整时点研究数据。
- EMA参考从输入首根收盘价开始，按 `adjust=False` 递推。券商可能加载更长的全历史，而原Python工具默认只取末60/120根；即使都叫EMA20，种子不同也会造成数值和临界信号差异。必须保持相同复权和历史起点、足够预热才能逐值比较，不能仅凭公式结构宣称实际客户端名单完全等价。
- 公式读取的是所选周期的行情。当日日线在盘中未结束，`C/H/L/VOL`会继续变化，当前信号可能消失；日线技术初筛不能证明某个较早时刻已具备收盘后才知道的条件。参数比较建议选择已收盘交易日。
- Python参考拒绝重复列/日期、混合股票、带时区日期、非有限数值、负量和矛盾OHLC。客户端计算依赖其行情库质量，不会执行这套Python输入校验。停牌和股票范围应在客户端另行设置。

离线测试覆盖EMA主信号与现有Python相同历史逐段比较、跳空核心严格阈值、尾盘涨幅端点、三档技术子集关系、预热和日期截断、未来数据追加不改写过去结果，以及源码单输出与禁用函数检查。测试没有调用客户端公式引擎，不等于实际券商编译或跨数据源一致性测试。

## 官方函数依据

`EMA`采用指数递推，`MA`为简单平均，`REF(X,N)`向前取值，`COUNT`统计窗口内成立次数；`BARSCOUNT`与本次载入的有效数据量有关，`VOL`在通达信中以手计。本目录仅使用当前及向前引用。函数语义核对于2026-11-17，参见[通达信官方函数列表](https://help.tdx.com.cn/gspt/docs/markdown/redword/functionlist.html)。

官方[条件形态示例](https://help.tdx.com.cn/gspt/docs/markdown/tdxgs-1d1olc9o6k8n8/tdxgs-1d1om6jqglcas.html)列出开盘突破上一根最高价的表达；[公式分类说明](https://help.tdx.com.cn/gspt/)规定条件选股只有一个输出；[基本概念](https://help.tdx.com.cn/gspt/docs/markdown/tdxgs-1d1k7b2r1ihug/)解释`:=`赋值、`:`输出及公式编辑器入口。本文提供原始文本，客户端版本功能以其编辑器帮助和实际编译结果为准。
