# EMA20 趋势与缩量回踩判断

对单只 A 股计算 EMA、MACD、成交量和乖离率，输出规则匹配报告。它不自动交易，也不输出经验证的收益预测。

在仓库根目录运行：

```bash
python ema/ema20_judge.py 000001 --profile standard --no-realtime
python ema/ema20_judge.py 000001 --profile strict --as-of 2026-09-04 --history-days 120 --style short
python ema/ema20_judge.py 000001 --profile standard --realtime
```

输出 Markdown 默认保存到 `ema/`，`--out` 可指定文件路径。`--as-of` 只接受不晚于今天的 `YYYY-MM-DD` 日期；非交易日使用截止日之前最近的有效日线。

## 三档筛选条件

| 参数 | 强限制 strict | 标准 standard | 弱限制 relaxed |
| --- | --- | --- | --- |
| `TOUCH_PCT`，回踩容差 | 1% | 2% | 3% |
| `SHRINK_RATIO`，缩量上限 | 0.65 | 0.80 | 0.95 |

参数位于 `SCREEN_PROFILES`，命令行 `--profile` 选择，默认标准档。回踩条件为 `最低价 <= EMA × (1 + TOUCH_PCT)`；同时要求收盘价高于 EMA。缩量条件为 `当日量 < VOL_MA 日平均量 × SHRINK_RATIO`，目前均量包含当日量。该口径与“仅以前 N 日计算均量”不同。

主信号还要求趋势向上：近 10 根日线中 EMA 末值高于首值，或至少 6 根收盘价在 EMA 上方。固定相同数据、风格和其余设置时，主信号的强限制通过集合包含于标准，标准包含于弱限制。这个关系只针对缩量回踩主信号，不能推广到报告中的风险提示、反抽信号或完整交易结果。

三档是便于观察信号数量变化的工程起始值，未经收益优化。强限制更容易漏掉机会，弱限制会增加噪声；不要把“强限制”理解为风险更低或收益更高。

## 可以修改什么

| 设置 | 位置/选项 | 默认值与可试范围 | 含义 |
| --- | --- | --- | --- |
| 截止日 | `--as-of` | 不填为当前；填任一有效历史日期 | 显式截止日禁用当前实时行情 |
| 日线数量 | `--history-days`，兼容 `--days` | 默认 60；可试 60/120/250，至少 `EMA_PERIOD + 5` | 请求约两倍自然日窗口，保留最多指定数量的交易日线；停牌等情况可能不足 |
| 实时追加 | `--realtime`，旧 `--no-realtime` 兼容 | 默认只用日线；盘中观察需显式加 `--realtime` | 默认前复权日线；实时模式改用未复权历史与今天原始报价，成交量统一为手 |
| EMA 周期 | `CONFIG['EMA_PERIOD']` | 默认 20；可试 10/20/30 | 修改后图表列名仍为 `ema20`，报告会显示实际周期；会改变策略含义 |
| 均量周期 | `CONFIG['VOL_MA']` | 默认 5；可试 5/10 | 修改后内部列名仍为 `vol_ma5`，实际计算按配置周期执行 |
| 放量倍数 | `CONFIG['EXPAND_RATIO']` | 默认 1.5；可试 1.3/1.5/2.0 | 只改变放量破位提示，不是主信号筛选门槛 |
| MACD | `MACD_FAST/SLOW/SIGNAL` | 默认 12/26/9；建议先保留 | 辅助趋势确认 |
| 震荡提示 | `OSC_LOOKBACK/CROSS_MIN/AMP` | 默认 20/4/0.05 | 仅提示，不会自动剔除股票 |

`--style long/short` 与筛选档位独立。`long` 的乖离倍数为 3、下限 6%、上限 15%、连续破线 3 日；`short` 为 2.5、5%、10%、2 日。这些配置在 `STYLE_PROFILES` 中修改。`CONFIG` 中旧的 `BIAS_TOO_BIG` 和 `CLEAR_DAYS` 未控制当前主流程，不应通过修改它们来调整风格。自适应乖离计算仍使用固定 20 根日线。

## 日期和数据限制

指定截止日会截掉截止日以后的日线，并禁止追加当前实时报价。历史报告仍使用数据源当前提供的前复权日线，可能包含后来发生的复权调整；这不是保存了当时数据版本的时点数据库，也不是无前视偏差的交易回测。数据源无法取到历史窗口时会报错，不会使用当前报价代替。

默认不追加实时报价，旧 `--no-realtime` 参数继续兼容。显式 `--realtime` 时，日线与实时报价均采用未复权价格，避免混合复权口径；东方财富日线的成交量以手计，新浪备用日线和实时报价的成交量从股除以100转换为手。未复权序列遇到除权除息会出现机械价格跳变，实时模式也不能据此判断经济收益。

实时数据必须是今天的日期，旧日期或未来日期会被拒绝；同日记录只保留一根，合并后按日线排序。指定 `--as-of` 始终关闭实时追加。主备源都会检查重复日期、缺失/非有限数值、价格为正、成交量非负及高低价关系；最新日线成交量为零时拒绝生成信号，不把坏数据当作“缩量机会”。

盘中成交量尚未结束，实时量比和完整日线量比无法直接比较。公开研究和三档对比使用默认日线模式，并手动选择最近已收盘日。报告中的“建仓/减仓”等词只描述规则匹配，不应作为实盘指令。`--out` 指向新目录时会自动创建父目录，写入失败会明确报错。
