# 参数、日期与三档版本

先固定数据和时间，再比较参数。下表是筛选偏好的工程配置，不是投资建议，也不是通过收益优化得到的推荐买卖阈值。严格档可能没有候选；弱限制会保留更多噪声，不能以“选得更多”评价效果。

## 1. 尾盘规则

用 `--profile strict/standard/relaxed` 选择；也可以修改 `tail_screen/wei_pan_core/config.py` 的 `SCREEN_PROFILES` 对应字段。直接改 `HARD_RULES_MODE_B` 的同名值会被档位选择覆盖，应修改 `SCREEN_PROFILES`。

下列是 **模式 B、市场闸门中性** 时的基准值：

| 筛选参数 | 强限制 | 标准 | 弱限制 | 配置字段 / 单位 |
|---|---:|---:|---:|---|
| 当日涨幅 | 2.5%–6% | 2%–7% | 1%–8.5% | `pct_chg`，小数 |
| 总市值 | 40–150 | 30–200 | 20–300 | `market_cap`，亿元 |
| 量比 | 1.3–4 | 1.1–5 | 1–6 | `vol_ratio`，倍数 |
| 换手率 | 6%–12% | 5%–15% | 3%–20% | `turnover_rate`，小数 |
| 至少一次涨停的回看窗口 | 20 | 30 | 45 | `limit_up_days`，交易日 |
| 收盘相对 MA20 偏差 | ±3% | ±5% | ±8% | `ma20_deviation_band`，小数 |
| 当日振幅下限 | 3% | 3% | 2% | `amplitude_min`，小数 |

`--mode A/B/C` 是另一维：A 使用较早窗口并附加形态/板块排除，B 为标准窗口，C 为较晚窗口并放宽部分形态。不能把 A 与 strict、C 与 relaxed 混为同一个选项。模式 K 系数和市场闸门会进一步改变有效区间，先用 `--show-config` 查看中性闸门下的阈值，实际运行再查看报告里的有效参数。

例如只比较档位，应始终使用相同模式：

```bash
python tail_screen/wei_pan_cli.py --profile strict --mode B --show-config
python tail_screen/wei_pan_cli.py --profile standard --mode B --show-config
python tail_screen/wei_pan_cli.py --profile relaxed --mode B --show-config
```

更多规则、评分权重、数据缺失行为和日期边界见 [尾盘说明](../tail_screen/README.md)。小市值、较高换手和涨停历史都是风格偏好，不代表低风险。默认公开入口只做规则排序。

## 2. 本地模型

公开 CLI 的三档只改变 `model_probability` 的入围门槛：0.65 / 0.60 / 0.55。`--min-probability` 可覆盖；这些概率未经独立校准，不能解释为真实盈利概率。

常用修改：`--days 730/1500/2500`（自然日回看）、`--forward-days 1/3/5`（交易日预测步长）、`--return-threshold 0.005/0.01/0.02`（标签涨幅小数）。改变标签或步长后，需要重新训练，不能直接比较原来的准确率。

原九条件筛选与原预测类保留在 `local_model/experimental/`；它们不是默认 CLI 流程。原筛选的低价、流通市值、PB/PE、窗口振幅、接近低点、量能等可改常量和三档手工设置建议见 [本地模型说明](../local_model/README.md)。`FINANCIAL_PERIODS` 可手工更新财报期末配对；报表期末不是披露日期，修改它也不会回放当时的价格和股票池。

## 3. EMA 缩量回踩

`--profile strict/standard/relaxed` 分别使用：

| 条件 | 强限制 | 标准 | 弱限制 |
|---|---:|---:|---:|
| 回踩容差 `TOUCH_PCT` | 1% | 2% | 3% |
| 缩量上限 `SHRINK_RATIO` | 0.65 | 0.80 | 0.95 |

在 `ema/ema20_judge.py` 的 `SCREEN_PROFILES` 中修改；`--style long/short` 单独控制乖离和破线提示，并非强弱档位。

`--history-days 60/120/250` 控制最多保留的日线根数，不是自然日天数。EMA 周期可在 `CONFIG['EMA_PERIOD']` 试 10/20/30；改变周期也改变策略含义。具体触碰定义、当日均量口径和仅作为提示的参数见 [EMA 说明](../ema/README.md)。

## 4. 跳空高开

| 条件 | 强限制 | 标准 | 弱限制 |
|---|---:|---:|---:|
| 总市值区间（亿元） | [30,80) | [20,100) | [10,200) |
| PB 上限，且 PB>0 | 5 | 10 | 15 |
| 开盘超过上一交易日最高价 | >0.5% | >0% | >0% |

可用 `--min-market-cap-yi`、`--max-market-cap-yi`、`--max-pb`、`--min-gap-pct` 覆盖。这里的 `--min-gap-pct 0.5` 表示 0.5%；而尾盘的百分数配置常用 0.005 表示 0.5%，两者单位不同。

定义始终是开盘突破上一交易日最高，不会把“开盘高于昨收”混成严格缺口。`--lookback-days` 为自然日窗口，建议起点 40，可在 20–90 间调整。详细 CSV 格式见 [跳空说明](../gap_screen/README.md)。

## 日期能改什么，不能改什么

| 模块 | 参数 | 实际支持 | 不支持的解释 |
|---|---|---|---|
| 尾盘 | `--date YYYY-MM-DD` | 仅上海时区今天；最新快照筛选，休市可能是旧快照 | 改日期即完整历史回放 |
| 本地模型 | `--end-date YYYY-MM-DD` | 截断日线；显示实际最后一根 K 线日期 | 保存了当时股票池和当时数据版本 |
| EMA | `--as-of YYYY-MM-DD` | 截断日线并禁用当前实时追加；休市取之前有效日线 | 无前视偏差的交易回测 |
| 跳空离线 | `--date YYYY-MM-DD` | 必须提供同日估值快照与目标日/上一交易日日线 | 最新 PB/市值可用于任意历史日期 |
| 跳空最新 | `--live` | 只允许今天，使用最新快照；未核验快照所属交易日 | 获取日期即已验证的行情日期 |

为避免盘中数据未完成的影响，日线研究宜指定最近已收盘日。需要真实历史表现时，还需补充当时可得的股票池、估值、价格版本、交易费用和成交限制。
