# 策略与交易规则说明

这里记录规则筛选什么、如何由 Python 实现、结果该怎样阅读。三档参考参数是便于比较的起点，没有经过独立样本收益优化。

## 1. 尾盘趋势与活跃度筛选

**思路**：先限制涨幅、市值、量比和换手，再检查近期强涨幅日、均线形态、价格相对 MA20 的距离以及指定时间窗口内的分时表现；通过后按规则和板块信息评分。

**Python 实现**：`tail_screen/wei_pan_core/` 将取数、股票池、硬过滤、规则评分和报告拆成独立模块。公开 CLI 固定纯规则排序。市值、量比等是快照字段，日内分钟数据用于二次检查，缺失时不能当作通过。

**结果阅读**：候选排序取决于本次实际数据与阈值。程序对分钟请求、板块映射等有数量上限，不代表完整、无遗漏的全市场排名；接口失败或日缓存过旧也会影响结果。

**退出规则**：原代码为候选附上次日竞价退出、开盘窗口止盈止损、较晚窗口追踪退出等模拟说明。止损、止盈和时间配置在 `SELL_STRATEGIES`；它们只是阈值描述，不代表预计成交价或收益。竞价价未知，跳空与涨跌停都可能使成交偏离阈值。改变退出规则不会自动产生一套已验证回测。

**三档取舍**：强限制缩小涨幅、市值等允许区间并收紧部分技术条件；弱限制扩大候选范围。`--mode A/B/C` 与档位独立，不应用不同分钟窗口直接比较档位优劣。

## 2. 本地技术指标模型与原九条件筛选

此目录保留两条不同的研究路径，默认命令行入口和原实验源码分别说明。

**默认模型入口**：先计算均线、RSI、MACD、KDJ、布林位置及量价等技术特征，再训练固定随机森林。标签表示从当前收盘到第N个后续交易日收盘的收益是否达到门槛，不是期间曾触及该涨幅；标签0也包含上涨但未达到门槛的情况。按时间顺序留出验证，并隔开预测步长，最后用全部已知标签数据重训，对最新有效日线计算概率。

**结果阅读**：`model_probability` 是模型输出，未经过独立概率校准，不能当作实际盈利概率；`selected` 只表示达到所选档位。改变预测步长或标签涨幅门槛，会改变学习任务，应重新训练并与同任务基准比较。

**原九条件筛选**：`experimental/screen_stocks.py` 保留低价、流通市值、PB/PE、财务同比、长窗口价格区间、接近低点、量能与周月形态等规则。可修改常量及强/标准/弱手工参考值见模块说明。行业代理标注不能证明企业股权性质，营收同比也不直接等于订单增长。

**原自动模型**：`experimental/predictor.py` 保留原模型选择、集成和校准实验。已修复一处标准化量纲问题，但其内部调参与切分没有完成全面时序审计，不能据此宣称准确率或交易效果可靠。

**交易规则边界**：概率筛选没有实现完整的开平仓、成本和组合收益评估。默认输出预测信号，不自动生成真实订单。

## 3. EMA 趋势中的缩量回踩

**思路**：在 EMA 趋势向上或近10根中多数收盘位于 EMA 上方时，检查最低价是否触及 EMA 上方一定容差、收盘是否仍高于 EMA、当日量是否低于指定比例均量。强/标准/弱档改变触碰容差和缩量上限。

**Python 实现**：`ema/ema20_judge.py` 计算 EMA、MACD、量能、自适应乖离和震荡提示。主信号、辅助确认和风险提示分别输出；MACD零轴等辅助条件并非主信号的必要条件。

**需要留意的定义**：目前触碰仅要求最低价不高于 EMA 上方容差，收盘仍高于 EMA；不是严格的“最低价必须落在对称区间内”。均量包含当日量。比较券商公式与 Python 时，需要统一这些定义及历史窗口。

**交易规则边界**：报告包含缩量回踩、破线、放量破位、持续未站回等条件描述。默认只使用日线；历史研究指定已收盘日。显式实时模式的成交量尚未完成，不能与完整日线直接比较。

**三档取舍**：同一数据和其它参数不变时，更窄容差与更低量能比例会减少主信号。但报告中的其它提示和完整交易结果不保证同样的包含关系。

## 4. 跳空高开

**思路**：目标交易日的开盘价必须严格高于上一实际交易日最高价，再叠加市值区间、正 PB 的上限、非 ST/退市及正成交量过滤。强限制增加最低缺口幅度并收紧部分估值/市值范围。

**Python 实现**：`gap_screen/screen_gapup.py` 先用同日快照筛选估值和交易状态，再取目标日及上一实际交易日日线验证缺口。不能用“开盘高于昨收”代替“开盘高于昨高”。周末和长假也不能简单用日历日期减一。

**结果阅读**：`gap_above_high_pct` 是开盘超过昨高的比例；`open_vs_previous_close_pct` 是开盘相对昨收的比例，两者分母不同。

**交易规则边界**：该模块定义入围事件，没有实现缺口回补、退出时点或持仓收益。高开并不保证当日继续上涨，盘后观察到的成交量也不能视为开盘前已知条件。

**历史数据要求**：历史筛选必须提供当时的市值/PB与股票池快照。最新快照仅适合最新筛选；日期标签本身不能证明数据来自当时。
